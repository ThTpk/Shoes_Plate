# Shoes_Plate — จากแผนที่แรงกดใต้ฝ่าเท้า สู่รูปทรงแผ่นรองเท้า

### ▶ เปิดเว็บแบบจำลอง: **https://thtpk.github.io/Shoes_Plate/**

ปรับผลรวมเกาส์เซียนได้ 1–5 หลุม · หมุนแผ่นรองเท้า 3 มิติด้วยเมาส์ ·
นำเข้าภาพฝ่าเท้าของคุณเองแล้วให้ระบบฟิตรูปทรงให้ · ทำงานในเบราว์เซอร์ล้วน ไม่ส่งข้อมูลออก

เครื่องมือวิเคราะห์แรงกดใต้ฝ่าเท้าจากชุดข้อมูล **StepUP-P150** และแปลงเป็นรูปทรง
แผ่นรองเท้าเฉพาะบุคคล พร้อมเว็บอธิบายแบบโต้ตอบ

ชุดข้อมูล: 150 คน · เดินเท้าเปล่าและใส่รองเท้า 4 แบบ · 4 ความเร็ว ·
เซนเซอร์ 4 ตัว/ตร.ซม. ที่ 100 Hz · [doi:10.20383/103.01285](https://doi.org/10.20383/103.01285)

## แนวคิดหลัก

แผ่นโฟมทำตัวเป็นแผงสปริงอิสระ (Winkler foundation) ความแข็งต่อหน่วยพื้นที่คือ
`k₀ = E / h₀` ดังนั้นความลึกที่โฟมยุบตัวคือ

```
c(x, y) = p(x, y) / k₀
```

จากนั้นย่อแผนที่ความลึก 3,000 พิกเซล ให้เหลือพารามิเตอร์ไม่กี่ตัวด้วยผลรวมเกาส์เซียน

```
c(u, v) = Σₖ Aₖ · exp[ −(u−uₖ)²/2σ²ᵤ,ₖ − (v−vₖ)²/2σ²ᵥ,ₖ ]
```

โดย `u` คือแนวขวางเท้า `v` คือแนวยาว (ส้น −1 → นิ้ว +1) ทั้งคู่ปรับมาตรฐานให้เท้าทุกคน
เทียบกันได้ **เกาส์เซียน 3 ก้อน (15 ตัวเลข) ได้ R² = 0.972** ขณะที่พหุนามดีกรี 5
(21 ตัวเลข) ได้เพียง 0.774 — เพราะเกาส์เซียนควบคุมเฉพาะที่ ปรับก้อนหนึ่งแล้วส่วนอื่นไม่ขยับ

## เว็บแบบจำลอง (`index.html`)

ไฟล์เดียวจบ ไม่มี dependency ภายนอกนอกจากฟอนต์ — เปิดจากเครื่องก็ได้
(`python -m http.server` แล้วเข้า `localhost:8000`) หรือเปิดจาก GitHub Pages ด้านบน

1. **แรงกด → ความลึก** เลือกตัวอย่างเท้า 3 แบบ ปรับ E และ h₀ ดูผลทันที
2. **จุดกดหนัก → A, uₖ, vₖ, σᵤ, σᵥ** คลิกบนรอยเท้าแล้วดูการวัดทีละขั้น
   พร้อมกราฟหน้าตัดที่ลากเส้นครึ่งยอด (σ = HWHM ÷ 1.1774)
3. **ผลรวมเกาส์เซียน 1–5 หลุม** ปรับทุกพารามิเตอร์ เห็นผลทั้งภาพ 3 มิติที่หมุนได้
   และแผนที่มองจากด้านบนพร้อมวงรี 1σ · เลือกขอบแผ่นได้สองแบบ คือตารางความกว้าง
   ครึ่งหนึ่งเทียบ v (สองข้างสมมาตรเสมอ) หรือเส้นโค้งปิดเบซิเยร์ 9 ช่วง
   ที่ใช้จุดยึดตั้งต้นจาก `bezier.html` (แต่ละข้างเป็นอิสระ จึงเว้าที่อุ้งเท้าด้านในได้
   โดยขอบด้านนอกยังเกือบตรง) — สลับแล้วพารามิเตอร์เกาส์เซียนไม่เปลี่ยนสักตัว
   เพราะขอบกับผิวอยู่บนพิกัด u, v เดียวกันแต่เป็นคนละสมการ
4. **ตัวอย่างจริง 10 ราย** จากชุดข้อมูล
5. **นำเข้าภาพเอง** รองรับภาพสี jet และเฉดเทา ฟิตอัตโนมัติแล้วรายงาน R²
   และพื้นที่แผ่น · เลือกขอบได้สองแบบเหมือนหัวข้อ 3 (ขอบเปลี่ยนเฉพาะรูปทรงแผ่น
   ส่วนการฟิตอ่านจากภาพแรงกดล้วน ๆ จึงไม่ขยับตาม)

3D renderer เขียนด้วย Canvas ล้วน (painter's algorithm + backface culling)
ไม่ได้ใช้ไลบรารีภายนอก

## ขอบของแผ่น (`bezier.html`)

ผลรวมเกาส์เซียนบอกว่าผิวแผ่นนูนลึกแค่ไหน แต่ไม่ได้บอกว่าแผ่นจบตรงไหน
ส่วนนั้นใช้เส้นโค้งเบซิเยร์ดีกรีสามต่อกันเป็นวงปิด

```
B(t) = (1−t)³P₀ + 3(1−t)²t P₁ + 3(1−t)t² P₂ + t³P₃      0 ≤ t ≤ 1
```

หน้านี้มีสี่ส่วน: ช่วงโค้งเดียวที่ลากจุดควบคุมได้พร้อมการแบ่งของเดอ กัสแตลโยและกราฟ
พหุนามแบร์นชไตน์ · การแปลงสมการเป็นเส้นที่วาดได้จริง (แตกเป็น `x(t)`, `y(t)`
กระจายเป็นฐานกำลัง แล้วเทียบการแบ่ง `t` เท่ากันกับการแบ่งครึ่งแบบปรับตัว) ·
ขอบปิดจากจุดยึด 9 จุดตามจุดสังเกตทางกายวิภาค (ก้านคำนวณด้วยคาร์ทมูล–รอม
จึงได้ C¹ อัตโนมัติ) · และการฟิตขอบจากรอยเท้าจริงในชุดข้อมูล

ส่วนที่สองมีแผง **ตัวอย่างคำนวณ ทีละบรรทัด** ที่กางให้ดูตั้งแต่แทน P ลงในสูตรสัมประสิทธิ์
ไปจนถึงคำสั่ง `moveTo` / `lineTo` ที่ส่งเข้าแคนวาสจริง และคิดค่า x(t), y(t) ให้สามวิธี
(ถ่วงน้ำหนักแบร์นชไตน์ · ฮอร์เนอร์บนฐานกำลัง · เดอ กัสแตลโย) เพื่อให้ตรวจสอบกันเองได้

ความคลาดเคลื่อนของการแทนเส้นโค้งด้วยเส้นตรง N ท่อนลดลงตาม `1/N²` (วัดได้ 3.8–4.2 เท่า
เมื่อเพิ่ม N เป็นสองเท่า) ส่วนการแบ่งครึ่งแบบปรับตัวไม่ได้ประหยัดท่อนกับเบซิเยร์เส้นเดียว
แต่ให้ขอบบนที่พิสูจน์ได้โดยไม่ต้องเดา N และประหยัดจริงเมื่อเป็นสายหลายช่วงที่ยาวไม่เท่ากัน
— ขอบแผ่น 14 ช่วงที่ความละเอียด 0.1 mm ใช้ 136 ท่อน เทียบกับ 210 ท่อนถ้าใช้ N ค่าเดียว

การฟิตทำทีละช่วง โดยตรึงจุดปลายและทิศสัมผัสไว้ เหลือตัวไม่รู้ค่าแค่ความยาวก้าน
`P₁ = P₀ + α₁t̂₁` และ `P₂ = P₃ − α₂t̂₂` ซึ่ง `B(t)` เป็นเชิงเส้นใน α ทั้งคู่
จึงเหลือระบบสมการ 2×2 ต่อหนึ่งช่วง แก้ด้วยกฎของคราเมอร์ แล้วขยับ t
ด้วยนิวตัน–ราฟสันอีกไม่กี่รอบ

ขั้นก่อนหน้าใช้สนามระยะทางมีเครื่องหมาย (signed distance field) ตัวเดียวทำสองงาน:
เชื่อมพื้นที่สัมผัสที่ขาดจากกันตรงอุ้งเท้า และขยายขอบออกจากรอยเท้าเป็นขอบแผ่น
— ทั้งคู่คือเส้นระดับคนละเส้นของสนามเดียวกัน จึงไม่มีปัญหาขอบพับทับตัวเอง
แบบการเลื่อนจุดออกทีละจุด

ที่ 14 ช่วงโค้ง (84 ตัวเลข) ขอบที่ได้เพี้ยนจากขอบดิบราว 0.6–1.3 mm RMS
เทียบกับเซนเซอร์ที่กว้าง 5 mm ต่อช่อง

## รูปทรงแผ่นรองเท้า

`insole_3d.py --profile` เลือกได้ 4 แบบ:

- **`cushion`** (ค่าเริ่มต้น) — หนาที่สุดใต้จุดแรงกดสูง ผิวบนนูนขึ้น ผิวล่างนูนลง
  เท่ากัน เนื่องจาก `k = E/h` โฟมที่หนากว่าจึงนุ่มกว่า — เป็นการทำสมการ
  `k ∝ 1/p` ด้วยรูปทรงแทนการเปลี่ยนวัสดุ
- **`split`** — สะท้อนกันรอบระนาบกลางเช่นกัน แต่บางลงใต้จุดแรงกดสูง
- **`shell`** — เปลือกหนาคงที่ ทั้งสองผิวโค้งตามรูปเท้า
- **`carve`** — แผ่นแบน เจาะเฉพาะผิวบน

STL ที่ส่งออกเป็น mesh ปิดสนิท (ผิวบน ผิวล่าง และผนังข้างรอบขอบ)

## ข้อจำกัด

- Winkler สมมติให้สปริงแต่ละจุดอิสระต่อกัน ของจริงโฟมดึงกันเอง
  รูปทรงที่ได้จึงคมกว่าความเป็นจริงเล็กน้อย
- ใช้เฟรมที่ลงน้ำหนักสูงสุดเฟรมเดียว ไม่ได้จำลองการกลิ้งของเท้าตลอดช่วงก้าว
- กฎของฮุกใช้ได้จนโฟมถูกกดราว 30% เกินกว่านั้นต้องใช้แบบจำลองไม่เชิงเส้น
- ยังขาด `participant_metadata.csv` จึง normalize ด้วยน้ำหนักตัวไม่ได้
- **เป็นการคำนวณเชิงวิศวกรรมจากข้อมูลแรงกด ไม่ใช่การสั่งจ่ายทางการแพทย์**
